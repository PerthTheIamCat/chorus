# Provider icons

Marks bundled in `apps/macos/Sources/Chorus/Resources/` (drawn as one-colour templates):

| File | Source | License of the file |
|---|---|---|
| `provider-claude.svg` | [Simple Icons](https://github.com/simple-icons/simple-icons) `claude` | CC0 |
| `provider-gemini.svg` | Simple Icons `googlegemini` | CC0 |
| `provider-openai.svg` | Iconify `logos` set (`openai-icon`) | see the set's license |
| `provider-antigravity.svg` | lobe-icons `antigravity` (size attributes dropped) | MIT |

The licenses cover the SVG files only. The marks are trademarks of Anthropic,
OpenAI and Google. Chorus shows them solely to identify which provider an
account or model belongs to (nominative use), never as its own branding, and
should not recolour or alter them beyond a single-colour tint. Check each
company's brand guidelines before using them anywhere outside the app UI
(website, store listing, marketing).
