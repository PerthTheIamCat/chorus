# Local router comparison — 2026-10-05

Ollama client/server 0.35.1. The four models ran sequentially on the same
machine with the same 34 manually labeled Chorus prompts (17 Thai, 17 English),
the same 12 ready candidates, and the same eight-second routing timeout.
Each model was warmed before timing. p95 includes `/api/show` capability
discovery and routing inference. All model files were below 2 GB.

| Router model | Correct route / 34 | Thai / 17 | English / 17 | Manual selections | p95 |
| --- | ---: | ---: | ---: | ---: | ---: |
| qwen2.5:3b | 12 | 6 | 6 | 0 | 3,609 ms |
| qwen3:1.7b | 12 | 7 | 5 | 0 | 1,319 ms |
| tev1:0.8b | 14 | 8 | 6 | 7 | 601 ms |
| chorus-openthai-systemone:0.8b | **17** | **9** | **8** | 4 | **450 ms** |

The OpenThai alias produced more exact matches and lower p95 latency than
the existing `qwen2.5:3b` default on this set. It manually deferred 2 of
4 deliberately ambiguous prompts, and also deferred 2 ordinary review
prompts. The current chat models deferred none of the ambiguous prompts.

The decision gate uses the joint probability of the selected task kind and
difficulty. A threshold sweep on the same set gave:

| Minimum joint probability | Exact matches / 34 | Manual selections |
| ---: | ---: | ---: |
| 0.35 | 17 | 4 |
| 0.45 | 17 | 8 |
| 0.55 | 12 | 18 |
| 0.65 | 10 | 22 |

Keep **0.35**: raising the threshold did not improve exact route matches and
made ordinary review tasks defer more often. This threshold is provisional;
the same examples were used for selection and evaluation, so the result is
not a calibrated estimate of real-world confidence.

These are smoke-test results, not a general accuracy claim. The prompts and
expected routes were written for this comparison and were not sampled from
real Chorus traffic. Repeat on a larger, blinded task set before treating the
5-case lead over the old default as settled. The raw per-case outcomes from
the local run are available in `/private/tmp/chorus-router-eval.json` on the
test machine; rerun the command in this directory to reproduce the summary.
